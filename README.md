# Features
- Full editor
- GLTF and OBJ loading
- FMOD audio
- Helpers (named positions)
- Rigidbody physics
- Post-processing shader pass
- Light sources
- UI system and 2D drawing
- Particle System
- Cross-platform build system for Windows and Linux
- Animation system using shape keys
- Frustum culling
- A simple profiler in the editor
- Shadow map for directional lights
